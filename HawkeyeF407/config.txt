# STM32F407 Pinout & Hardware Configuration

This document contains the complete hardware pinout and peripheral configuration mapping for the STM32F407 flight controller board based on the schematics.

## 1. IMU SPI & Compass / Magnetometer
### IMU SPI (GY 91)
____________________________________________________
| GY-91| STM32F407 PINOUT|        Function         |
|------|-----------------|-------------------------|
|  SCL | PB13 / SPI2_SCK | SPI Clock		   |
|  SDA | PC3 / SPI2_MOSI | SPI Master Out Slave In |
|  SDO | PC2 / SPI2_MISO | SPI Master In Slave Out |
|  NCS | PB12 / MPU_CS   | Chip Select             |
|  CSB | PB14 / BARO_CS  | Barometer Chip Select   |
|  3V3 | 3.3V            | Power Supply            |
|  GND | GND             | Ground                  |
----------------------------------------------------

### Compass QC (HMC5883L)
_______________________
| HMC5883L | STM32F407 |
|----------|-----------|
|   VIN    |    3.3V   |
|   GND    |    GND    |
|   SCL    |    PB10   |
|   SDA    |    PB11   |
------------------------
